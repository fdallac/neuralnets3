Detailed Description

template<typename T>
class OneHotEncoder< T >

One-Hot Encoder for categorical variables (sklearn-style API)

Template Parameters
TNumeric type (float, double, etc.)

Converts integer class labels to one-hot encoded vectors. Supports fit/transform pattern for consistent encoding across train/test sets.

Example:

OneHotEncoder<double> encoder;
Matrix<double> y_encoded = encoder.fit_transform(y_train);
Matrix<double> y_test_encoded = encoder.transform(y_test);
Matrix
Dense matrix class with row-major storage.
