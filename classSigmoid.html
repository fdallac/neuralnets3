Detailed Description

template<typename T>
class Sigmoid< T >

Sigmoid activation function.

Template Parameters
TNumeric type (float, double, etc.)

Applies the sigmoid activation: f(x) = 1 / (1 + exp(-x)) Derivative: f'(x) = f(x) * (1 - f(x))

Output range: (0, 1). Commonly used for binary classification.

Warning
Can suffer from vanishing gradients for large |x|
