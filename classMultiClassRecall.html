Detailed Description

template<typename T>
class MultiClassRecall< T >

Multi-class recall metric (macro-averaged)

Template Parameters
TNumeric type (float, double, etc.)

Computes macro-averaged recall across all classes. For each class c: Recall_c = TP_c / (TP_c + FN_c) Macro recall = mean of all class recalls
