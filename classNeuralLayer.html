Detailed Description

template<typename T>
class NeuralLayer< T >

Represents a single layer in a neural network.

Template Parameters
TNumeric type (float, double, etc.)

Stores weights, biases, gradients, and cached values for forward/backward passes. Uses He initialization for weights to prevent gradient vanishing with ReLU.
