Detailed Description

template<typename T>
class Optimizer< T >

Abstract base class for optimization algorithms.

Template Parameters
TNumeric type (float, double, etc.)

This class defines the interface that all optimizers must implement. Optimizers are responsible for updating model parameters based on gradients.
