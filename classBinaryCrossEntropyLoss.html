Detailed Description

template<typename T>
class BinaryCrossEntropyLoss< T >

Binary Cross-Entropy loss function.

Template Parameters
TNumeric type (float, double, etc.)

Computes binary cross-entropy loss for binary classification: BCE = -(1/n) * Σ[y*log(p) + (1-y)*log(1-p)]

where y is the target (0 or 1) and p is the predicted probability. Uses epsilon (1e-12) to avoid log(0).
