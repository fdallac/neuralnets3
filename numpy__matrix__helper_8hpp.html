Detailed Description

Zero-copy conversion utilities between NumPy arrays and C++ Matrix.

This header provides internal utilities for converting between NumPy arrays and the C++ Matrix class.

template<typename T>
py::array_t< T > pynn3::internal::matrix_to_numpy_zerocopy ( Matrix< T > && matrix)

Create a NumPy array that owns Matrix memory (zero-copy)

Moves the Matrix into a capsule so NumPy owns the memory. The Matrix is consumed - do not use it after this call.

This is the preferred method for returning large results to Python as it avoids unnecessary data copying.
