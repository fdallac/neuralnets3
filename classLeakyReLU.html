Detailed Description

template<typename T>
class LeakyReLU< T >

Leaky Rectified Linear Unit (LeakyReLU) activation function.

Template Parameters
TNumeric type (float, double, etc.)

Applies the Leaky ReLU activation: f(x) = x if x > 0, else alpha * x Derivative: f'(x) = 1 if x > 0, else alpha

Uses alpha = 0.01 to prevent dead neurons by allowing small negative gradients. This solves the "dying ReLU" problem.
