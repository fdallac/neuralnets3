Detailed Description

template<typename T>
class CategoricalCrossEntropyLoss< T >

Categorical Cross-Entropy loss function.

Template Parameters
TNumeric type (float, double, etc.)

Computes categorical cross-entropy loss for multi-class classification: CCE = -(1/n) * Σ Σ y_ij * log(p_ij)

where y is the one-hot encoded target and p is the predicted probability distribution. Uses epsilon (1e-12) to avoid log(0).
